- Role-based login: Allows Managers, Tutors, and Employees to
access the system through role-specific accounts.

- User and role management: Organises access according to each
user's assigned role and responsibilities.

- CSV data storage: Reads and stores application records using CSV
files in a dedicated data folder.

- Schedule management: Supports managing tutor schedules and
viewing relevant scheduling information.

- PDF schedule export: Exports schedule information as a PDF for
convenient sharing or printing.

- Email reminders: Sends email reminders to help users keep track
of scheduled sessions and important events.

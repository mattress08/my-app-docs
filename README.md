App name - Tutoren

Tutoren will be a cloud-based student, tutor, and employee management application built using python and flask. It will allow managers to add/edit/delete students, tutors, and employees, and assign students to tutors, and automatically create schedules in a PDF format. The application will also conflict check, to prevent double booking. Tutoren also automatically send emails to both students and tutors as reminders.  
The application reduces discrepancies by 55%. The application will serve to reduce human error and save time.
